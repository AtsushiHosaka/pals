# モデル呼び出し時間を最短にする方針の測定計画 2026-11-07

測定の実行前に、仮説と判定の規則を固定するための計画です。**結果を見てから規則を変えません。** 実行はまだしていません。費用はまだ発生していません。

## 目的

証明1件あたりの**モデル呼び出し時間の合計**を最短にする。制約は、一発で通る確率を落とさないことと、並列にして費用を増やさないことです。

## 設計の要点: 既存の有料データを再利用する

過去の2つの実行は、カード群が異なります（Luna 12枚、Terra 12枚）。このため、モデルの差は交絡しています。**互いのカード群を相手のモデルで走らせれば、同じ24枚が両方のモデルで揃います。** 新しい24枚を集めるより安く、比較も正しくなります。

| 0 | 準備（無料）。pals-agent を固定コミット（`adec962`）で別の作業ツリーに用意し、`tools/mathlib_index/hint_ab.py` と Lean 固定版を確認する。1問を予算0.05ドルで試走する。 | 0 |

各実行は1回あたり1ドル未満で、予算上限（`--max-usd`）を実行ごとに付けます。合計は約1.2ドルです。実行はすべて**逐次**です（並列にしない。時間の測定が互いに干渉しないため）。

## 事前に固定する仮説

- **H1（推論の量）:** Terra medium から low に下げると、1件あたりのモデル時間が短くなり、成功の数は1枚以内の差に収まる。
- **H2（モデル）:** 同じカードで、Terra は Luna より、成功が多く、修復が少なく、時間の合計が短い。
- **H3（振り分けの手がかり）:** 文に `∀`/`∃` を含むカードは、Luna が失敗する。**この予測は固定済みで、Terra の12枚のうち該当する4枚（`orientation_counterexample`、`lagrange_multiplier_from_direction`、`limit_order`、`basis_recognition`）は、段階1aで Luna が失敗すると予測する。** 残り8枚は成功すると予測する。これは学習に使っていない検証データです。

## 比較する方式（段階3の机上計算）

- **A:** Terra を最初から使う。
- **B:** Luna で修復 k 回（k=2, 3）まで試し、通らなければ Terra へ。
- **C:** `∀`/`∃` を含むカードは Terra へ直行し、含まないカードは B と同じ。

修復回数は上限6で実行し、k への切り詰めは記録から計算します。Terra へ上げた後は、Terra 単独の実行と同じ時間と費用がかかると仮定します（Luna の失敗の文脈を渡さない）。

## 判定の規則（事前固定）

1. 制約: 成功数が Terra medium より2枚以上減らず、1問あたりの推計費用が0.08ドル以下。
2. 制約を満たす方式のうち、**1問あたりのモデル時間の平均が最短**のものを選ぶ。
3. 差のブートストラップ95%区間が0をまたぐなら、**最も単純な方式（A）を選ぶ**。
4. H3は、予測と結果の一致が **12枚中10枚以上**のときだけ、方式Cを検討する。満たさなければ、方式Cは不採用。

## 記録する項目

試行ごとに、次を記録します。質問本文、Lean本文、利用者情報は含めません。#217の項目と同じです。

- カードID、モデル、推論の量、試行番号
- 直前のLean診断コード、その試行のモデル時間とLean時間
- 入力トークン、キャッシュされた入力トークン、推論トークン（キャッシュの命中率も見る）
- 成功・失敗、修復回数、費用の推計

## 限界

- **1セルあたり1回の実行です。** モデルの出力は揺れるので、小さな差は検出できません。n=24で、大きな差だけを見ます。
- ハーネスは、全ロールに1つのモデルを使います（`--model`）。「Luna で `sketch` し Terra で `prove`」のような混在は測れません。測るにはハーネスの変更が必要です。
- ローカル実行で、通信の時間が含まれます（本番の AWS とは異なります）。
- ストリーミングの効果は測りません（完了までの時間は変わらないため）。
- 費用はアプリの推計値です。

## 前提と停止条件

- `OPENAI_API_KEY` は、利用者の環境変数に設定済みであることが前提です。**キーの値は、チャット・ファイル・ログに出しません。** 未設定なら、実行を始めずに依頼します。
- いずれかの実行で、予算上限に達するか API エラーが続いたら、その場で止めて報告します。
- 終了後、作業ツリー、一時ファイル、Lean のビルド成果物は削除します。
