# 数式の表示ルール

学習者に見せる証明・回答・説明・補足では、数式を KaTeX で表示できる TeX として書く。
文中は `$...$`、独立した式は `$$...$$`（既存の `\(...\)`・`\[...\]` も表示側で対応）。
変数、所属、根号、冪、等式、不等式を本文の文字や Unicode 記号だけで書かない。

例：`x^m∈I` → `$x^m\in I$`、`x∈√(IJ)` → `$x\in\sqrt{IJ}$`。
表示側では、保存済みの生成回答・証明説明・追加質問の回答に残るこの種の明確な文字式も TeX として描画する。
推測が必要な普通の文章やコード断片、既に TeX で囲まれた式には手を加えない。

ユーザーが入力した命題、Lean コード、引用した出典はこの表示ルールによって
保存内容を書き換えない。生成回答はモデルへの指示と独立した品質確認の両方で
このルールを確認し、既存回答の表示補正はブラウザ内だけで行う。
