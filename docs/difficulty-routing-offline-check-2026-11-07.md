# Luna の失敗を事前に予測する手がかりの無料検証 2026-11-07

「最初に難しさを見て、難しければ Terra に直行する」案の前提を、**新しいモデル呼び出しなしで**確かめた記録です。費用は0です。結論は、**振り分けの根拠にはまだならない**です。

## 方法

- 対象: Luna low（修復上限6）で実行済みの12枚。結果は 6成功/6失敗 です（出典: 品質台帳 `2026-11-03-hint-ab-luna-low-cards12-baseline`、カードごとの結果は `mathlib-statement-index-2026-11-03.md`@47a397e の表）。
- 手がかり: カードの Lean の文（`docs/*.lean` の `manifest card` 直後）から、モデルを呼ばずに計算できるもの。文の長さ、束縛の数、`∀`/`∃` の数、固有の Mathlib 名の数。
- 照合: Luna の成功・失敗との関係。

## 結果

| 手がかり | Luna 失敗（中央値） | Luna 成功（中央値） |
|---|---:|---:|
| 文の長さ（文字数） | 206.5 | 200.0 |
| 束縛の数 | 8.5 | 8.5 |
| 固有の Mathlib 名の数 | 0.5 | 1.0 |
| **`∀`/`∃` の数** | **1.5** | **0** |

- 文の長さ、束縛の数、Mathlib 名の数には、差がありません。
- `∀`/`∃` を含む5枚は、すべて失敗でした。含まない7枚のうち、失敗は1枚だけです（`second_derivative_minimum`）。成功6枚はすべて `∀`/`∃` なしです。
- フィッシャーの正確検定は両側で p≈0.015 です。ただし、4つの手がかりを試した後に選んでいるため、補正すると p≈0.06 です。

## 判断を妨げる点

1. **n=12 で、手がかりを結果を見た後に選んでいます。** 偶然の一致の可能性が高いです。
2. **分野との交絡があります。** 成功6枚のうち4枚が線形代数、失敗は微積分・多変数・可換環論が中心です。`∀`/`∃` が分野の代理になっているかもしれません。
3. **独立した検証データがありません。** Terra の12枚で同じ手がかりを見ましたが、Terra は12枚中11枚が通るので、Luna の難しさの検証にはなりません。`∀`/`∃` を含む4枚のうち、失敗は1枚（`lagrange_multiplier_from_direction`）だけでした。
4. 他のLunaの結果（`exact-flow-luna-20`：16/20）は、カードごとの記録が見つかりませんでした。

## 次の一手

- 手がかり（`∀`/`∃` の有無）で振り分ける仮説は、**事前に決めた形で**、別の約20枚について、Luna 先行の実行結果と突き合わせる必要があります。その実行は有料です（Luna は安く、1問約0.01ドル）。
- そのとき、`sketch` の出力（使う補題の数と既知かどうか）も、同時に記録します。モデルを呼ばずに取れる手がかりが増えます。
- Luna 自身に難しさを尋ねる案は、上の手がかりが弱い場合だけ試します。

## 参考: 費用計算（振り分けが効くのは時間）

Luna 先行（失敗なら Terra）は、失敗確率 f が約63%以下なら、Terra 単独より安いです（`(1−f)×0.0021 + f×(0.0246+0.044) < 0.044`）。ただし、数字の定義が揃っていません（Luna は Sketch 以降のみ、Terra は問題全体）。振り分けで得られる主な利益は、Luna の失敗にかかる約766秒の短縮です。

> **訂正（2026-11-09、レビュー指摘）:** 上の約63%は、損益分岐の推定として読めません。計算は、Terra の費用 $0.044 を、全体でも Luna が失敗したカードでも同じと仮定しています。台帳の `2026-11-03-exact-flow-terra-deep4`（Luna が失敗した4枚を Terra medium で実行、修復上限12）は、4枚の合計が $1.64で、約 $0.41/枚です。仮定の約9倍で、仮定は測定と合いません。63% は仮の値として扱い、しきい値は、同じカードで Luna 先行と Terra 単独を対にした費用で推定し直すまで出しません。
