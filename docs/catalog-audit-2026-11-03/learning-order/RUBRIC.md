# 学習順序の審査（中学・高校）

目的: 各カードの `answer`（人間向けの模範解答）が、そのカードが属する学習段階より後に習う定理・道具を使っていないかを調べる。
証明が正しいかは問わない。使う道具の「習う時期」だけを見る。進んだ証明そのものは悪くない。初学者向けの標準解答として置いてよいかを判定する。

## 段階表（小さいほど先に習う。日本の学習指導要領）
S1 中1: 正負の数、文字式、一次方程式、比例・反比例、基本の作図、おうぎ形、空間図形の体積・表面積、代表値
S2 中2: 式の計算、連立方程式、一次関数、平行線と角、合同条件、三角形・四角形（平行四辺形）の性質、確率の初歩
S3 中3: 展開・因数分解（乗法公式）、平方根、二次方程式（解の公式）、関数 y=ax²、相似、円周角の定理、三平方の定理、標本調査
S4 数I: 文字式の工夫、実数・絶対値、一次不等式、集合と命題（必要十分、対偶、背理法）、二次関数、三角比（正弦定理・余弦定理・面積公式）、データの分析
S5 数A: 場合の数・確率（順列・組合せ・反復試行・期待値・条件付き確率）、整数の性質（約数倍数、互除法、不定方程式、n進法）、図形の性質（チェバ・メネラウス、円の性質、方べきの定理、内心外心重心）
S6 数II: 式と証明（二項定理、恒等式、等式・不等式の証明、相加相乗平均）、複素数と方程式（剰余定理、因数定理、解と係数の関係、高次方程式）、図形と方程式（直線・円・軌跡・領域）、三角関数（一般角、加法定理、合成）、指数・対数関数、微分・積分（多項式のみ。極限は直観的）
S7 数B: 数列（等差・等比・Σ・漸化式・数学的帰納法）、統計的推測（確率変数、二項分布、正規分布、推定、検定）
S8 数III: 極限（数列・関数・連続）、微分法（積・商・合成・逆関数、三角・指数・対数関数の微分、平均値の定理、増減・凹凸）、積分法（置換・部分積分・区分求積・面積・体積）
S9 数C: ベクトル（平面・空間、内積、直線・平面の方程式）、複素数平面（極形式、ド・モアブル、回転）、平面上の曲線（二次曲線、媒介変数表示、極座標）
S10 大学の入門以上: ε-δ、テイラー展開、線形代数、群・環など、高校範囲外の定理

注意:
- 数学的帰納法は S7（数B）。数列の漸化式も S7。整数の議論（数A）で帰納法を使うときは S7 を使ったと数える。ただし、解答が「帰納的に分かる」程度の記述に留まる場合は数えない。
- 背理法・対偶・場合分けは S4 以降で自由に使える。中学の証明に背理法は教科書上ほぼ出ない（S3 の √2 の無理数証明など例外あり）。
- 数IIの微分は多項式限定。数IIIの微分（積・商・合成、三角・指数・対数）は S8。
- 数IIの三角関数の加法定理は S6。数Iの三角比の段階（S4）では加法定理を使わない。
- ベクトル・複素数平面・座標は S9/S6。S3 以前の幾何、S5 の図形の性質は、座標・ベクトル・三角比・複素数を使わず、合同・相似・円周角・三平方・方べきなどの綜合幾何だけで書くのが標準。三角比 S4 は S5 の図形でも使ってよい。
- 平均値の定理、ロルの定理、テイラー展開、コーシー・シュワルツの一般形、イェンセン不等式、中間値の定理（ε-δ）、積分の一般論などは S8〜S10。
- 相加相乗平均(S6)を S4 の二次関数・不等式で使っていないか。二次関数の最大最小は平方完成（S4）で足りる。
- 剰余の定理・因数定理は S6。S3 の因数分解で使わない。

## カードの段階の決め方
1. 各カードの「本来の段階」`home` を、題意（statement・topic・level）から S1〜S9 のいずれかに決める。level が middle なら S1〜S3、high なら S4〜S9（複数の段階にまたがるときは、題意を述べるのに必要な最後の段階）。入試カード（entrance_exam）は題意の単元の段階とする。
2. `answer` が使う道具の最大の段階 `used` を決める。道具の例: 微分・平均値の定理・三角関数の加法定理・ベクトル・座標・複素数・帰納法・二項定理・剰余の定理・相加相乗・コーシー・シュワルツ・ジョルダン、など。
3. `used > home` なら違反。道具ごとに、その道具の段階、答案のどの行で使うか、home 以内の道具で書き替えられるか（できる／できない）を書く。
   - 定理名を挙げて引用するだけでなく、計算の中身が実質同じ道具である場合も数える（例: 二次関数の最大最小を微分して解いたら S6 の微分を使っている）。
4. 重大度:
   - major: home より2段階以上後の道具、または単元を丸ごと越える道具（中学の幾何でベクトル・三角比・座標を使う、数Iの二次関数を微分で解く、など）。
   - minor: 1段階だけ後の道具で、home の道具による代替が簡単に書ける。
   - note: 題意そのものが home より後の内容（level の貼り方が低すぎる）。答案ではなく level の指摘。
5. 代替が書けるときは、`patch.answer` に、home 以内の道具だけで書いた全文（日本語、KaTeX、既存の書き方に合わせる）を入れる。10行を超える書き替えが要るとき、代替が存在しないときは patch を付けず、`fix` に方針だけ書く。**新しい答案は、元の答案と同じ主張を証明しなければならない。主張を弱めたり、仮定を足したりしない。**
6. 進んだ証明を、削除せず残す対象として別に数える: 違反だが「既習者の復習向けとして価値がある」答案は、`keep_as_advanced: true` を付ける（別カード化の候補）。

## 出力
JSON のみ。キー:
- `batch`: バッチ名
- `reviewed`: 審査枚数
- `ok_ids`: 違反なしの id の配列
- `findings`: [{id, home, used, severity(major|minor|note), tools: [{tool, stage, where, replaceable(bool)}], fix, patch: {answer: "..."} または省略, keep_as_advanced(bool)}]
- `systematic`: 系統的な問題（例: 「この単元の標準解答が毎回微分を使っている」）の文字列配列
- `home_assignments`: {id: "S?"} の辞書（全カード。後で集計に使う）
