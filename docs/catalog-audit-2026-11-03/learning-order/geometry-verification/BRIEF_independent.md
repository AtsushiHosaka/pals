# 幾何カードの書き替え案（patch_answer）の独立検査

PALSの教材カタログのカードには、人が読む模範解答 `answer` がある。学習順序の審査で、中学・高校の幾何カードの多くが、題意の学年より後に習う道具（ベクトル・内積・座標・三角関数など）で解かれていると指摘された。各指摘には、題意の学年（`home`）までの道具だけで書き直した案 `patch_answer` がある。あなたの仕事は、この書き替え案を1枚ずつ、独立に検査することである。書き替え案の作者の意図や、`original_answer`・`tools`・`used` に引きずられず、自分で数学を確かめること。

## 段階表

## 検査項目（カードごと）
1. **math_valid**: 書き替え案の各ステップは真か。飛躍はないか。`home` 以下の学年で既習の教科書の定理（合同条件、平行線と角、円周角の定理、方べきの定理、メネラウスの定理など）は、名前を挙げて使ってよい。未習の定理の使用、「明らか」で済ませた核心、場合分けの漏れ（点の位置が違う図、退化した場合）は不備とする。
2. **same_claim**: 書き替え案は、カードの `statement`・`assumptions`・`conclusion` と同じ主張を、同じ仮定のもとで証明しているか。仮定の弱め忘れ・強め（図を1つに決めつける、非退化性を暗に足す、次元を2に決める）や、結論の部分的な証明は不備とする。
3. **order_ok**: 書き替え案が使う道具のうち、`home` より後の段階のものはないか。あれば道具名とその段階を挙げる。教科書の流れ（その学年で、その定理より前に習っているか）まで確かめる。段階表で同じ段階でも、節の順序で後になるものは指摘する。
4. **circular**: 結論と同値の主張や、このカードの結果を使って示す後続の定理を前提にしていないか。
5. **lint**: 日本語は10行以内、「概略」という語を使わない、絵文字・em dash なし。長ければ指摘する。

## 判定
- `pass`: 5項目すべて問題なし。
- `fix`: 小さな修正で通る。`fixed_answer` に、修正後の全文を書く（`patch_answer` と同じ体裁。LaTeXは `$...$`）。
- `fail`: 学年内の道具では、そもそも題意を証明できない、または大がかりに作り直す必要がある。理由と、見込みのある方針を `note` に書く。

## 注意
- 数学の確認は、自分で図を描き、反例を探す気持ちで行う。「もっともらしい」だけで pass にしない。
- 書き替え案が正しくても、`home` が不自然に低い（題意が実は高校範囲）と思ったら `home_comment` に書く。
- 推測できないことは `note` に「不明」と書き、断定しない。
- `fix` の `fixed_answer` も、自分で同じ検査を通してから出す。
- ファイルの編集はしない。結果は指定の出力ファイル1つだけに書く。

## 出力
JSON配列を、指定のファイルに書く。要素は次の形。
{"id": "...", "verdict": "pass|fix|fail", "math_valid": true/false, "same_claim": true/false, "order_ok": true/false, "circular": false/true, "lint_ok": true/false, "problems": ["具体的な不備を1行ずつ。なければ空"], "fixed_answer": "fixのときのみ", "note": "failのとき、または補足", "home_comment": "任意"}
最後に、pass/fix/fail の件数だけを短く報告する。
