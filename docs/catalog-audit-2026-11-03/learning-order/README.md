# 学習順序の審査（中学・高校）2026-11-03

## 対象と方法

- 対象は `pals-agent/testdata/textbook-catalog-v1` の `level` が middle / high のカード842枚と、入試カード43枚（`entrance_exam`）である。ほかに、`geometry_homotopy` の中学・高校のカードも含む。凍結した時点は、監査の修正332枚を適用したコミット `75c7383` である。
- 大学範囲のカード（約1,170枚）は審査していない。
- 道具の習う時期は、`RUBRIC.md` の段階表（S1 中1 〜 S10 大学）で決めた。審査者は1枚ずつ、題意の本来の段階 `home` と、答案が使う最大の段階 `used` を判定し、`used > home` を違反とした。
- 17バッチをサブエージェントで並列に審査した。`batches/` に審査者の出力、`findings.json` に違反209件がある。系統的な問題は `systematic.md` にある。

## 主な発見

1. **問題は幾何に集中している。** 違反209件のうち123件（59%）、major 152件のうち109件（72%）が L13〜L16 である。代数・解析は、ほとんどのバッチで違反が1割以下だった。
2. **原因は、幾何の題意が一般形で書かれていることである。** 題意が「実内積空間上のアフィン空間」で書かれているため、答案もベクトル・内積（数C）で組まれる。中学の三角形・円や、数Aの五心・円の性質までが、ベクトルで証明されている。重心がベクトル式で定義されているため、ベクトルを含まない重心のカードまで答案がベクトルになる。外心を原点とする同じ段落が、垂心・九点円・オイラー線の複数カードに貼られている。
   - 違反の段階の組み合わせで最も多いのは、数A（S5）の題意に数C（S9）の道具を使う40件、中3（S3）に S9 を使う25件、中2（S2）に S9 を使う15件である。
   - カードの題意の一般形は、方針（変数で書く）に沿っている。直すのは題意ではなく、人が読む答案である。Lean の証明は一般形のままでよい。
3. **指数・対数は、実数べきの定義が数IIIに寄っている。** 17件はどれも、a^t = e^{t log a} と定義して自然対数と e を使う型である。常用対数・対数の定義・指数関数の単調性で書き替えられる（14件）。3件は、e による定義の証明を進んだ証明として残す案になっている。
4. **中間値の定理を、数I・数IIの存在証明に使っている。** 二次関数2件、三角関数6件。判別式や単位円上の点の動径の角で書き替えられる。
5. **数学的帰納法（数B）と Σ 記号が、数A・数II・中学のカードに入っている。** 指数法則、和の法則、多項式の係数、合同式のべき乗など。
6. **学年の貼り方（level）のずれが25件ある。** 例: 三角形の内角の和が level middle なのに、題意が実内積空間で書かれている。確率の等確率カードが middle なのに、題意が集合記号と要素数で書かれている。入試カードは全部 level=1 で、段階が決まらない。
7. **進んだ証明として残す候補が102件ある。** 答案が学年を越えるが、既習者の復習に価値があるもの。これは削除せず、別カード化するか `proof_method_tag` で区別する案になる。

## 審査の限界

- **書き替え案145件のうち、幾何の82件だけを検査した（次節）。** 残る63件（代数・解析・入試）は未検査である。前回の監査では、検査を通らない案が9%、意味が誤りだった案が5%あった。同じ程度の誤りが残る可能性がある。面積カード9枚の案は、三角形の面積を底辺×高さ÷2として既知にする前提に立つ。この前提を許さないなら使えない。
- **段階表は粗い。** 同じ科目の中の順序を捉えない。数列は、教科書では帰納法の節より前に一般項・Σ・漸化式があるが、段階表では同じ S7 なので違反にならない。数IIの微分と多項式も同様である。この粒度まで守る方針なら、違反は増える。
- **`home` は審査者が1枚ずつ判断した。** 境界のカードは判断がぶれる。`tetrahedron_*` の3枚は S9（数C）としたが、数Aの空間図形とみなすなら違反になる。
- **大学範囲のカードは未審査である。** 学年は「大学何年」の4段階だけで、道具の順序表がまだない。
- 適用側の `catalog.py check` は通していない。書き替え案は日本語の答案だけで、Lean の証明は変えない。

## 幾何の書き替え案の検証（L13〜L16、82件）

独立した検査者4人が21件ずつ、`BRIEF_independent.md` の項目（数学の正しさ、題意との一致、学年内の道具、循環、体裁）で検査した。続いて、別の指示（欠陥を探す）の検査者2人が、無作為に選んだ24件を再検査した（`BRIEF_adversarial.md`）。

| 検査 | 結果 |
|---|---|
| 独立検査（82件） | pass 68、fix 14、fail 0。fix は修正文つき |
| 敵対的再検査（24件の抽出） | pass 23、flaw 1（minor） |
| 機械的な文体検査（修正後の82件） | 失敗 0（7件は `×` と `(i)` が `$` の外にあり、直した） |

`verified_answers.json` に修正後の答案82件がある。`status` は次のとおり。

- **verified（50件）**: 検査を通り、弧度法の問題もない。
- **verified_with_radian_caveat（30件）**: 検査は通ったが、答案が弧度法（π）を使う。弧度法は数II（S6）なので、`home` が S5 以下のカードでは、段階表の上では違反になる。カードの題意自体が π で書かれているものが15件ある。度数法に直した検査者（6件）と、そのままにした検査者がいて、基準がそろっていない。方針を決めてから、全件を同じ基準でそろえる必要がある。
- **hold（2件）**: `convex_polygon_interior_angle_sum`、`convex_polygon_exterior_angle_sum`。カードの凸性は「向き付きの符号条件」で定義されている。答案はこれを「対角線が内部にある」という教科書の凸に読み替えており、同値は学年内で示せない。敵対的再検査でも指摘された。

そのほかの注意点は次のとおり。

- 面積カード9枚は、面積を底辺と高さの積の半分として既知にする。カードの定義は凸包のルベーグ測度なので、読み替えの前提が要る。
- `home` の見直し案が出ている。`slant_equal_iff_foot_equal`（S5→S3）、`equal_chords_iff_equal_center_distance`（S4→S3）、`common_chord_perpendicular_bisected_by_center_line`（S5→中2〜中3）。
- 敵対的再検査は24件の抽出である。残る58件は、独立検査1回のみを通っている。
- Lean の証明とカタログ契約検査（`catalog.py check`）は通していない。答案の日本語だけを検査した。
