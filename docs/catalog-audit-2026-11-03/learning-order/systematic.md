# 系統的な問題（バッチ別、審査者の記述）

## L1

- 指数法則の標準答案が再帰定義と数学的帰納法（S7）に依存している。中2の単元の定理を、数Bの道具で証明している。個数の数え上げによる説明を標準に、帰納法版は上級カードとして分ける。
- levelの貼り方がずれたカードが多い。連立方程式の二元の解の公式など、道具は中2の消去法だけのカードが level=high で、中学の枠に収まる内容が high に置かれている（違反ではない）。逆に fundamental_theorem_symmetric_polynomials は level=2 という不正な値で、題意が大学入門に入る。
- ファイルの大半（絶対値・平方根・因数分解・連立方程式・比例式）は、分配法則、因数分解、場合分けだけで書かれていて、学習順序に問題がない。唯一の例外は、中学の平方根（S3）で背理法（S4）が出る点。

## L2

- school_integers の累乗・指数を扱うカード（add_dvd_pow_add_pow_odd、prime_dvd_of_dvd_pow、coprime_pow_pow、congruence_pow、base_expansion_exists_unique）の標準解答が、数Aの整数の議論で形式的な数学的帰納法（S7）を使っている。素因数分解の一意性・合同式の性質・割り算の繰り返しなど、数Aの道具で書ける。
- 一般の指数 n の和・差の恒等式（b^n-a^n の因数分解、(b-1)(1+b+...+b^k)=b^{k+1}-1）を、補足なしに使う答案が複数ある（compare_powers_nonneg、digit_length_iff_pow_bounds、low_digits_remainder）。「隣り合う項が打ち消し合う」形か、不等式の性質を繰り返す形に直せる。
- school_inequalities の level: middle の4枚（ineq_mul_sign_rule、range_of_sum_and_difference、linear_ineq_by_coeff_sign、sq_add_sq_ge_two_mul）は、答案は中学の道具で足りるが、題意の単元が段階表では数I以上（一次不等式 S4、不等式の証明 S6）にあたる。level の貼り方の問題である。
- school_inequalities の不等式カードは、相加相乗・コーシー・シュワルツ・チェビシェフ・ネスビットを平方和の恒等式や因数分解で示していて、微分や大学の道具を使わず、段階の逆転は見つからなかった。平方完成・差の因数分解の型に統一されている。
- フェルマーの小定理のような高校範囲外の定理の引用は、このバッチでは prime_three_mod_four_dvd_sum_of_squares の1件だけ。互いに素なら倍数の余りが並べ替えになるカード（coprime_multiple_residues_permute）の議論で自給でき、他のカードに同種の引用は見つからなかった。

## L3

- 連続性・中間値の定理に頼る解答は2枚だけ。どちらも判別式と因数分解（$4af(x)=(2ax+b)^2-D$）で書き替えられる。
- 接線の3枚（parabola_above_tangent_line, tangent_line_difference_and_unique_contact, tangent_through_point_iff）は、題意が「接線」を使うので home を S6 とした。tangent_through_point_iff の答案が$f'(p)=2ap+b$を使うのは S6 の範囲内。S4 の単元に置く場合は、接線を代数的な定義（$L(x)$の式）で述べるカードに限る。

## L4

- Σ記号（数B数列で初出）が、整式の係数を扱う数II カードの標準の書き方になっている（even_odd, coefficient_comparison, rational_root, conjugate_root_theorem）。同じバッチの monic_integer などは「…」で書けており、展開形に統一すれば解消する。
- 数学的帰納法（数B）を、因数定理を繰り返し使う場面（product_over_distinct_roots_divides）と共役の累乗（conjugate_respects_arithmetic）で明示的に名乗っている。数II の式と証明・複素数の単元では「繰り返し使う」「最大の k を取る」で書くのが標準。
- remainder_by_square_of_linear と double_root_iff_value_and_derivative_vanish は微分（数IIの微分法）を使う。段階表では同じ S6 なので違反にしていないが、教科書の配列では『式と証明』『複素数と方程式』より後の単元。題意に P' が入っているため home は S6。未習順を厳密に見るなら、微分を前提にする別カード扱いが望ましい。
- 因数定理は S6 で、このバッチの多くが依存する。home が S6 なので問題はない。ただし factor_theorem_linear_ax_plus_b は x-c の因数定理を前提にしており、基礎となる x-c の因数定理そのもののカードが別にあるかは、このバッチからは確認できない。

## L5

- school_exp_log の標準解答は、実数べきを a^t=e^{t log a}（自然対数と指数関数 e、数IIIで初めて導入）で定義して証明する型が多い（17枚）。数IIの標準は「有理数列の極限で定める実数べき」「log_a M は a^p=M をみたす p」「常用対数」。定義文と補題の順序を数II版に合わせると、多くが自然対数を常用対数または定義そのものに置き換えるだけで直る。
- log_a x を log x/log a（自然対数の商）で定義する書き方が、不等式・方程式の複数カードで共通している。底の変換公式（カード logb_change_of_base）は定義に依らず a^p=b から導けるので、それを根拠にすれば自然対数は不要になる。
- 指数法則3枚（rpow_add_exponent_law, rpow_mul_exponent_law, mul_rpow_base_law）の e の定義による証明は、既習者の復習向けとして残す価値がある（別カード化の候補）。ただし、patch の有理数列の極限による証明は直観的な極限に頼るので、厳密さを求めるなら高校範囲では上限が見える。
- patch は、log_10 の単調性や a^t の単調性、log(M^p)=p log M を数IIの既知事実として使う。単調性の最初の根拠（指数関数が単調であること）は教科書では図示で与えられ、カタログ内に証明を持つカードは exp_lt_iff_base_gt_one などの本体であるため、依存順を検証するときは logb 系の他カードとの循環に注意する。

## L6

- sin, cos, tan の「値の存在」（全射性、主値の存在）を中間値の定理（数III）で示す答案が6枚ある。数IIでは単位円上の点と動径の角の対応（三角関数の定義）で足りる。同じカタログの harmonic_addition はすでにその書き方をしている。
- 加法定理・倍角・和積・積和は数II（S6）で、これらを使う答案は問題ない。単調性（sin_strict_mono_interval など）も和積の公式による符号判定で書かれており、微分を使っていない点は良い。
- 全カードのlevelは high だが、題意が実数 x とラジアンを含むため home は S6（数II）とした。『三角比』という topic 名のカードでも、題意は一般角なので S4 ではない。

## L7

- 全カードが数B（S7）の数列単元で、道具の段階は S7 以内に収まっている。指導要領の段階表の粒度では違反は上記1件のみ。
- 段階表では帰納法と数列を同じ S7 とみなすため違反にならないが、実際の教科書の単元順では、等差・等比の一般項、Σの公式、階差数列、漸化式の各節が「数学的帰納法」の節より前にある。arith_general_term、arith_sum_first_last、arith_sum_first_diff、geom_general_term、sum_natural_numbers、sum_squares_formula、sum_cubes_nicomachus などは、標準解答が帰納法で書かれており、同じ章の初学者には未習の道具になる。上の段階表では検出できない順序の問題なので、章内の順序まで守る方針なら、これらの定義に近いカードは「項を書き並べる」型の解答に直す価値がある（本審査では段階表に従い違反とはしていない）。
- sum_reverse_order のように、写像・全単射・単射などの大学入門の用語を一語使うだけの箇所が他のバッチにもありうる。用語の検索（全単射、写像、単射）で拾える。

## L8

- 微分・積分カードの大半は一般の連続・微分可能関数を扱う題意で、home は S8（数III）になる。そのため平均値の定理・合成関数の微分・部分積分・置換積分の使用は違反でない。違反は、題意が3次関数など数II（多項式）に限られるのに数IIIの道具（平均値の定理、第2次導関数の判定法）を使う2枚に集中している。
- 数IIの題意（3次関数の増減・極値）の標準解答は、平方完成と因数分解（f(y)-f(x), f(y)-f(t)-f'(t)(y-t) の因式分解）で書くのが学習順序に合う。cubic_minus_tangent_factorization の因数分解を土台にできる。
- 級数のカードで「絶対収束」「無条件に和をもつ」と書く箇所は、形式化側の Summable に引きずられた表現で、高校範囲外（S10）。geometric_series_tail と arithmetic_geometric_series は言い換えで解消できるが、geometric_series_convergence_criterion は題意自体に含まれる。
- 6分の1公式系（integral_sixth_formula など）は (x-α)^k の原始関数を、展開せず (x-α)^(k+1)/(k+1) として直接使う。厳密には1次式の合成の微分だが、数IIの教科書の6分の1公式の導出が同じ書き方をしているので違反にしていない。

## L9

- 高校範囲外の群論的な道具（置換の合成・互換・安定部分群）を数Aの組合せ論の答案で使うパターンが2枚あった（lot_drawing_position_fair, words_given_letter_counts_multinomial）。標準解は「順列の数で直接数える」「区別して数えて重複で割る」で書け、どちらも書き替え済み。

## L10

- 一部の円・円錐曲線カード（line_secant_circle_iff_dist_lt_radius など）はlevelがhighのみで、段階の幅が広い。home の割り当てが担当者で揺れやすいので、集計時は home_assignments の S6/S9 の混在に注意。

## L11

- 線形代数の語（部分空間・次元・直交分解）、外積、オイラーの公式で書かれた答案があった。いずれも、平面ベクトルの基本定理・連立方程式・加法定理による帰納法で置き換えられる。
- triangle_region_coefficients は題意が「凸包」で述べられており、level の貼り方が高校では低すぎる。

## L12

- データの分析17枚（school_data_logic の data_*）はすべて、題意も答案も有限集合上の Σ 記法で書かれている。Σ は数B（数列、S7）で初めて習う記号で、数Iの教科書は x_1+…+x_n と書く。論理は数Iの代数だけで閉じているため個別には違反に数えなかったが、数I向けのカードとして出すなら、記法の注意書きか、x_1+…+x_n 版の併記が望ましい。
- データの分析のうち、道具が範囲を越えたのは data_correlation_abs_le_one のコーシー・シュワルツのみ。同じ単元の data_correlation_abs_one_iff_linear は、平方和が0なら各項が0という論法で書かれており、標準的で適切。コーシー・シュワルツを使わない版の書き方が既にある。
- geometry_homotopy の6枚は、題意が実内積空間・アフィン空間・球面で書かれている。教科書の単元は中2（内角の和）、中3（三平方）、数I（余弦定理）、数A（方べきの定理・トレミー）で、level 表示（middle または high）と題意の抽象度が合わない。答案は題意に対して妥当だが、初学者向けの標準解答としては置けない。各単元の平面版を別カードとして立て、このバッチの5枚は既習者向けとして残す案を推奨する。inner_zero_iff_right_angle は単元が数C（内積）で答案が定義を展開するだけなので、違反とはしなかった。
- pythagoras_angle_iff は余弦定理（S4）から三平方の定理（S3）を導いており、教科書の順序（三平方→余弦定理）が逆になっている。抽象内積空間では角が内積で定義されるため循環ではないが、学習順序の観点では注意が必要。
- 集合の要素の個数（finset_card_*）、命題と条件・背理法・対偶のカード群は、集合の基本操作と論理だけで書かれており、問題なし。

## L13

- 平行線の同位角・錯角の4枚は、教科書でも証明なしで認める事実であり、置き換えるべき中学の証明が存在しない。公理扱いにするか、level を引き上げる必要がある。

- 多角形の内角・外角の和は、カード独自の『凸』の定義（有向角の符号）と帰納法に依存し、中2の標準（対角線で三角形に分ける）から大きく離れている。教科書の凸の概念とのずれがあるため、patchの正当性は『凸多角形は対角線で三角形に分けられる』を既知とすることに依存する。
- 四面体の対辺・重心・対辺の中点のカード（tetrahedron_*）は、題意の単元が数C（空間ベクトル）にあたると判断してS9を home とした。数Aの空間図形と中点連結定理で書けるとする別の判断もありうる。

## L14

## L15

- この単元の題意が『実内積空間上のアフィン空間』で書かれており、標準解答がほぼ毎回ベクトル・内積（S9）で組まれている。中3（円周角・弦・接線）と数A（方べき・接弦・2円の位置関係）の初学者向けカードとしては道具が数段階先に出ている。同じ内容は、二等辺三角形、三平方、OM⊥AB と OP²=OM²+MP²、三角不等式の等号、長方形の対角線、方べきの定理で書ける。
- 対策の核は『OM⊥AB（または O=M）かつ OP²=OM²+MP²（P は直線AB上）』の補題を1枚のカードにして、弦・接線・方べき・2円のカードがそれを引用する形にすること。今回のパッチも毎回この補題を再証明しているので、補題カード化すると各答案が短くなる。
- 内積版の一般次元の証明は、数C以降の復習用として別カードに分けて残す価値がある（keep_as_advanced=true）。ただし主張が『任意次元の球面』のままでは初学者向けの標準解答にならないので、初学者向けは『平面上の円』の主張に書き替える必要がある。
- 接線の定義（直線上の任意の点Uについて ⟨U-Z,Z-O'⟩=0）が接線を使う全カードの答案冒頭に内積の形で入っている。実際の推論は『接線は半径に垂直』と三平方だけのカード（tangent_lengths_equal、pitot、incircle など）が多い。これらは違反とはしなかったが、定義の一文を『半径に垂直な直線』に置き換えるだけで中3の道具に揃う。
