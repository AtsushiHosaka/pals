# textbook-catalog-v1 の審査 2026-11-03

Draft と Recipe の候補1,881枚について、日本語の文、OpenMath、Lean の定理文が同じ命題を表しているかを、1枚ずつ審査した。あわせて、大学数学の欠落分野と OpenMath の形式を調べた。

Lean のコンパイルは、カタログ作成側がすでに全件で通している。今回の審査が見たのは、コンパイルでは保証されない部分である。

## 対象と範囲

- 対象は `pals-agent/testdata/textbook-catalog-v1` の1,881枚（40ファイル）である。他チャット `claude/pals-draft-recipe-expansion-438936` が編集中のため、作業ツリーを凍結して審査した。基準は HEAD `f71a674` に未コミットの変更863件を加えた状態で、`cards/` と `vocabulary/` の YAML 全体の SHA-256 は `a928e2cd216d501ca237c8605e5f6c3ac4a3c345407db14b700a53636021221c` である。
- 本番に載っている既存の Draft/Recipe 行、旧来の型付きプロファイルのカード、`existing-recipes.tsv` の102枚は審査していない。
- 学習順序（初学者向けカードが未習の定理を使っていないか）は審査していない。この観点は審査後に追加された方針である。
- 方法は、全カードを18バッチに分け、サブエージェントが1枚ずつ判定した。調査は3本で、可換代数と代数幾何、大学数学全体、OpenMath の形式である。

## 結果

1,881枚のうち1,449枚（77%）は指摘なしだった。指摘が付いたのは432枚で、重大度は major 45、minor 387である。

エージェントが critical と判定した1件（`open_mapping_theorem`）は、major に下げた。カードIDは領域名つきで、Draft ID と Recipe ID に重複はない（`textbook.complex_analysis.open_mapping_theorem` と `textbook.functional_analysis.open_mapping_theorem` は別の ID になる）。ただし中身の違う定理が同じ名前で並ぶので、改名は必要である。

| 指摘の種類 | 件数 |
|---|---:|
| OpenMath の書き方が再利用に向かない（OM_FORMAT） | 140 |
| OpenMath が Lean の定理文と一致しない（OM_LEAN_MISMATCH） | 87 |
| 他のカードと重複（DUPLICATE） | 74 |
| 反例カードが反例になっていない（NEGATIVE_BAD） | 53 |
| 日本語の文と Lean の定理文の不一致（TEXT_LEAN_MISMATCH） | 35 |
| 名前に対して主張が弱い（WEAK_OR_OVERNAMED） | 30 |
| 不必要な定数・特殊形（SPECIAL_CONSTANT） | 23 |
| ラベルの誤り（MISLABEL） | 14 |
| 模範解答の誤り・飛躍（ANSWER_WRONG） | 13 |
| Lean の既定値頼み（JUNK_VALUE） | 13 |
| Lean の定理文が名前の主張と違う（TARGET_UNFAITHFUL） | 4 |

件数は指摘の重複を含む。バッチごとの内訳は `batches/` の JSON にある。

## 主な発見

1. **Lean の定理文は、おおむね忠実である。** 定理文が名前の主張と違うものは4件、既定値頼みは13件にとどまる。欠陥の中心は OpenMath である。
2. **OpenMath が Lean の定理文より弱い。** 仮定や台集合の情報が落ちて、別の設定では偽になる主張を表してしまう。例は次のとおり。
   - 幾何で、平面の仮定が落ちる（円のカード16枚。うち7枚は3次元や1次元では偽）。
   - 位相で、写像の連続性が落ちる（`covering_path_lifting`、`covering_lift_uniqueness`）。
   - 線形代数で、正方性が落ちる（`left_inverse_is_right_inverse`）。
   - 図式のカードで、可換図式の写像に型がない（`five_lemma_modules`、`short_five_lemma_modules`、`snake_lemma_modules`）。
3. **反例カードが、反例になっていない。** 指摘は53件ある。典型は「未定義」を理由にした反例で、Lean では `x/0=0` であり、`Real.logb` や `tan` も仮定なしで値を持つため、仮定を落とした主張がそのまま定理になる。`tan_add_formula`、`logb_change_of_base`、`log_composite_derivative` などで確認し、代わりの反例が提案されている。残りは、わざとらしい反例や、具体的な反例を欠くものである。
4. **Mathlib の定義がそのまま主張になっているカードがある。** `noetherian_iff_ideals_fg`、`valuation_ring_element_or_inverse`、`spectrum_closed_sets_are_zero_loci` など。`advanced_undergrad` では約15枚が、公理や定義の言い換えである。網羅の数字を水増しするので、別に数える必要がある。
5. **同じ概念に別のシンボルがある。** 同義のシンボルが75組あり、283枚に影響する。`pals2` のシンボル1,055個のうち448個は、1枚のカードだけで使われている。命題ごとの専用述語が多い。
6. **OpenMath の構造類似度が、定理とその逆を区別できない。** 類似度の高い上位40ペアのうち、危険なものが12組あり、うち8組は定理とその逆である。向き（`>` と `<`）と可換な引数の順序を正規化していないため、同じ定理の別の書き方（平均0.79〜0.86）が、逆の定理（0.88〜0.94）より低くなる。試作では、変数のつながりと前提・結論の役割を加えると、逆ペアの類似度が約0.5に下がった。実クエリでは未検証で、埋め込み側（重み40%）も未測定である。判定は「形式は維持して修正」である。詳細と統合表は `openmath_format_audit.md` と `openmath_symbol_merges.json` にある。

## 分野の欠落

詳細は `gap_commalg_ag.md` と `gap_university.md` にある。

- **可換代数**は、各章の看板定理が1〜3枚ずつ、最も弱い形で並ぶ。証明が実際に引く補題（有限族の prime avoidance、radical の計算、局所–大域原理、行列式トリック、整従属の推移律）がない。A–M より先（高さ、Krull の標高定理、dim R[X]、正則列、depth、正則局所環、Tor/Ext）は0枚である。次元論のカードは「PID は dim 1」と「体は dim 0」の2枚だけである。
- **代数幾何**は0枚で、Spec の位相に関する3枚だけがある。Mathlib にはスキーム、構造層、Proj、準連接層が既にある。
- 「可換代数」と名付けたカード（可換代数・環論・加群の132枚）のうち約27%は、一般の環・加群・圏の補題である。逆に A–M 第1章と第7章の内容（約27枚）は `ring_theory` にある。`topic` の付け替えが必要である。
- 大学範囲1,019枚のうち level 4 は16%で、証明の約70%は4行以下（中央値3行）である。4年から修士の分野で、カードが0〜6枚の分野が約25ある。優先度の高い穴は、Fourier 解析の主定理、特殊関数、確率分布と特性関数、初等整数論の定番、マルチンゲール、組合せ論、Ext・群コホモロジー、計算可能性である。穴の多くは Mathlib に定理があり、カード化されていない領域である。

## この審査の限界

- 修正案333件の検証は次節に書いた。OpenMath が意味として正しいかは、標本60件の独立検査までで、残り約140件は意味の確認をしていない。
- 実際のクエリでの検索性能は測っていない。
- 2件の数字は、エージェントの報告を再集計して訂正した。1枚だけで使うシンボルは、出現回数ではなくカード数で数えた448個が正しい。大学範囲で証明が4行以下の割合は70%である（エージェントの報告は75%）。
- 凍結した作業ツリーは、他チャットの進行によって変わりうる。適用の前に再照合が要る。

## 修正案の検証

修正案333件を、凍結カタログのコピー上に適用して検証した。他チャットのカードには書き込んでいない。`verification/` に、検証スクリプト、結果、検証済みの差分がある。

| 検証 | 結果 |
|---|---|
| カタログの契約検査（実バリデータ、全語彙）。修正案をそのまま適用 | 333件中30件が失敗。24件は宣言していない新記号の使用、6件は既存記号の引数の数や役割の食い違い |
| 同、新記号を語彙に追加し、食い違う6件を別の記号へ置き換えたあと | 失敗0件 |
| Lean の定理文・証明の修正31件を、許可した公理だけでコンパイル | 31件すべて成功 |
| OpenMath 修正案の意味を独立に検査（標本60件。major はすべて含み、残りは無作為） | 正しい56件、誤り3件、判断不能1件 |
| 誤りと判定された3件を、検査者の修正案へ差し替え、契約検査 | 失敗0件 |
| 修正適用後の全1,881カードで `catalog.py build` | 成功。OpenMath の衝突0件 |

- 修正案自身の検証が甘かった。契約検査を通らない修正案が9%あり、独立検査の標本でも5%（3/60）は意味が誤っていた。誤りの3件は、元の欠陥（前提の脱落）を直したつもりが、別の前提（被覆写像 p と空間 E、X の対応、近似列の非負性、自己写像の条件）を落としたものだった。標本外の約140件は、同じ割合で誤りが残る可能性がある。
- 修正の副作用として、15カードが `generic_now`（デプロイ済みのバリデータで読み込める）から `needs_vocabulary`（`pals2` の受け入れ後でなければ読み込めない）へ移る。OpenMath を忠実にしたために新しい記号が要るためである。一覧は `verification/tier_changes.json` にある。
- 新しい `pals2` 記号が24個要る（`verification/vocabulary_additions.yaml`）。
- `ring_theory.quotient_lift_unique` は `ring_quotient_lift_unique` に改名される。
- 適用は `verification/apply_validated_patches.py` で行う。差分（`validated_patches.json`、332カード）を、カタログの checkout の YAML に当てる。凍結時点から checkout が動いている場合は、カードが見つからないと報告して止まる。
- 適用していない項目が1つある。`associated_primes_finite` の模範解答に、文を1つ加える提案（`answer_note`）である。この提案は理由の部分が誤りだった。根基が素イデアルでも Ann(x) が primary とは限らない（k[x,y] の (x²,xy) が反例）。適用側が結論（ネーター環で2つの定義の集合が一致する）だけを残し、理由を使わない直接の証明に差し替えた（commit 75c7383、ブランチ `claude/textbook-catalog-v1`）。`ALL_FINDINGS.json` の `answer_note` は使わないこと。
