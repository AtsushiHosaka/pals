# AWS Architecture Icons

Unmodified SVGs selected from the official AWS Architecture Icons package released on 2026-07-31.

- Source and usage guidance: https://aws.amazon.com/architecture/icons/
- Exact download URL, package SHA256, original ZIP paths, and individual SHA256 values: [provenance.json](provenance.json).
- Copyright: Amazon Web Services, Inc. or its affiliates. The icons retain AWS ownership and usage terms; the repository license does not relicense them.

These assets are embedded into the draw.io document by `docs/diagrams/generate_architecture.py`. No remote image fetch is required to display or export the diagram. The Cloudflare and OpenAI nodes do not use AWS service icons.
