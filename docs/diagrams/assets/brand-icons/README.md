# ブランドアイコンの出典

[Simple Icons](https://simpleicons.org/) 14.15.0（CC0-1.0）の`cloudflare`・`openai`・`stripe`のSVGです。取得元は`https://cdn.jsdelivr.net/npm/simple-icons@14.15.0/icons/<name>.svg`です。

元SVGに塗り色（`fill`属性）だけを追加しています。形状は変更していません。ロゴの商標権は各社に帰属し、このリポジトリが各社の提携・推奨を受けていることを示すものではありません。接続先のサービスを示す目的に限って使用しています。
