# OBS-002: 初回否認の原因と回答言語の修正

[Issue #15](https://github.com/AtsushiHosaka/pals/issues/15) の初回回答は、数学的には正しかったが、日本語指定に対して英語だったため独立審査で否認された。審査を省略せず、受付で選んだ回答言語を生成と審査に共通で渡す。

## 保存された2回の記録を照合した

2026年10月8日11:49〜11:57 JSTの対象QAチャットだけを、既存の本番DBから読み取った。トランザクションは `REPEATABLE READ READ ONLY`、文ごとのタイムアウトは5秒とし、最後の `ROLLBACK` を確認した。取得数は1 request、2 claim、10 usage。生の生成文・審査記録・ログ・接続情報はこのリポジトリに追加していない。

|項目|初回|Retry|
|---|---|---|
|claim revision|1|3|
|生成された証明文|英語|日本語|
|独立審査|数学は正しいが、日本語指定に違反するため否認|導出が完全として承認|
|生成・審査モデル|OpenAI `gpt-6-luna`|OpenAI `gpt-6-luna`|
|preflightの正規化文|日本語で証明する指示を省略|日本語で証明する指示を保持|

保存されたrequestの `output_language` は両回を通じて `en` だった。初回のpreflightは理由欄で日本語指定を認識していたが、正規化文には残していなかった。否認理由は保存された審査記録から確定した。正規化文の違いが生成を左右した可能性はあるが、当時の完全なプロンプトと稼働imageは未確定であり、内部の生成理由までは断定しない。

## CORE-015の言語選択を生成と審査まで揃える

[CORE-015](../specs/pals-product-core/requirements.md) は、明示指定、依頼文の言語、直前の回答言語の順で選び、要求に保存して生成・審査で共用する仕様である。APIの既存PR #3はIssueの観測後にマージされ、依頼文から選ぶ処理を既に追加している。この処理を重複実装せず、残っていた明示指定の検出漏れを修正した。

- API: `prove … in Japanese`、`In Japanese, prove …`、日本語の「日本語で証明して」、中国語の証明指示を認識する。否定指定、引用、コード、資料の言語を回答言語と混同しない。
- Agent: `request.output_language` を回答・確認質問・入力候補の言語として明記する。数学用の正規化文や検索資料の言語から選び直さない。独立審査にも同じ規則を渡し、別言語の本文は否認する。
- API回帰テスト: 英語を初期値とするチャットで日本語を明示指定し、英語回答の否認、Retry、日本語回答の保存を通して `ja` を保持する。初回claimの審査理由・回答hash・usageを保持し、非公開の否認文を公開しない。

既存の生成済み履歴は書き換えない。審査条件、モデル昇格条件、呼出し回数の上限を変更せず、自動再生成を追加しない。

## 対数の単調性で検証した

新しい検証には正の実数における対数の単調性を用いた。Issueに残る旧題材は新しいテストに再利用していない。

Agentの関連unitテスト147件が成功した。4言語の伝達、正規化文が言語指定を省略する場合、別言語の否認、Recipeとtoken計測の審査経路を含む。providerのfixtureを使うunitテストは入力と制御の検証であり、実モデルの品質確認とは区別した。

実OpenAI呼出しは `gpt-6-luna` で4回。APIの言語選択関数で `ja` を選び、Agentのpreflight、生成、独立審査を実行した。平均値の定理による日本語の証明が承認され、同じ主張の英語回答を別の審査呼出しに渡すと日本語指定違反として否認された。この検証はカタログを使わない生成・審査経路で行い、本番アプリやDBへの書込み、Lean検証、deployは行っていない。

APIのunitテスト全体は2026件成功、1件skipだった。言語選択の回帰テスト97件を含む。skipはDocker環境のTesseractと言語データを必要とする既存OCRテストである。PostgreSQL 16でAPI統合テスト13件が成功した。既存の試験DBはhostからの認証に失敗したため、既存imageから試験用コンテナ1個を作成した。既存DB・role・認証を変更せず、終了時の試験DB残存0件とコンテナ・volumeの削除を確認した。

実装PRは [API #7](https://github.com/AtsushiHosaka/pals-api/pull/7) と [Agent #4](https://github.com/AtsushiHosaka/pals-agent/pull/4)。それぞれ `86546ef` と `4422d48` のpush成功後に親のsubmodule参照を更新した。監視「OBS-002 の作成確認と修正」は `PAUSED` のまま維持する。
