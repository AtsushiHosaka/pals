# PALSのLPと紹介動画の制作方針

LPはChatGPTの中央に質問入力欄を置く構成、動画はRaycastの操作画面を主役にした見せ方を参考にする。白・黒・グレーを使う。製品画面には、本物のPALSを操作した録画を使う。以前の再構成UIとLinearを中心にした構図案は採用しない。

実録26秒版を4種類制作した。PDF・行ホバーの追加撮影と公開は未実施。

## 参照した画面と映像

[ChatGPT](https://chatgpt.com/)のホームをブラウザで確認した。小さな見出し、中央の入力欄、広い余白をLPへ取り入れた。PALSの質問例、言語選択、ログイン、登録への導線は実際に使えるものを配置する。

[Raycast Notesの公式紹介](https://www.raycast.com/blog/raycast-notes)から、37秒の[「Friction.」](https://www.youtube.com/watch?v=8FTSAqNleuw)を参照した。0・7・11・22・29秒の画面と、途中の再生を確認した。短い導入の後は、ノートやコード、通話といった利用場面の操作が中心になる。PALSでは操作に合わせて画面へ寄り、読む場面で正面に戻す。Raycastの紫色の背景は使わず、白黒にする。音の分析は行っていない。

## 26秒版は、本物の説明とコードを見せる

日本語・英語、16:9・9:16の4種類をTesseractで編集した。映像は2026年9月29日に収録されたPALSの実操作であり、UI内の文章は変更していない。英語版も日本語UIの録画に英語字幕を添えたもの。音声は付けていない。

| 編集時間 | 元素材と区間 | 見せる内容 | 日本語字幕 |
| --- | --- | --- | --- |
| 0〜4秒 | search-source-fixed.mp4 / 70〜74秒 | 素数の整除問題と検証済みの説明 | ChatGPT、Claude、Gemini。AIの数学の説明、どこまで信用できますか？ |
| 4〜10秒 | 同上 / 35〜41秒 | 実際にLeanコードを開く操作 | 証明を、Leanコードでも確認。 |
| 10〜12秒 | new-proof-result.mp4 / 46〜48秒 | 別の問題で検証が進む画面 | 別の例：平方の展開をLeanで検証。 |
| 12〜17秒 | 同上 / 59〜64秒 | 検証済みの平方展開の説明 | 検証を通った証明と、その説明。 |
| 17〜22秒 | 同上 / 121〜126秒 | 実際の平方展開のLeanコード | 生成したコードまで確認できます。 |
| 22〜26秒 | 編集可能な文字レイヤー | PALSと利用先 | 数学の証明を、PALSで。 palschat.site |

元素材は親リポジトリの `output/playwright/main-validation-20260929/` にある。左のテスト履歴とアカウント、下端のURL表示をクロップで除いた。素数の問題と平方の問題は、字幕で別の例だと伝える。競合サービスの回答や失敗例は作らない。Leanによる検証は形式証明が対象であり、すべての回答の正しさを保証する表現は使わない。

PDF添付と行ホバーは、この録画には映っていない。現行のログイン済み画面で撮影してから追加する。LPの説明では、PDFの取り込みがPro向けであること、対応する説明があるコード行にカーソルを合わせる操作であることを記載した。Macの3Dモデルは含まない。

## 再編集に使うプロンプト

```text
PALSの紹介動画をTesseractで編集する。日本語と英語、横長16:9と縦長9:16を作る。
LPはChatGPTの中央入力型、映像はRaycast Notesの公式動画「Friction.」の操作中心の見せ方を参照する。
白黒を基調にし、製品画面を主役にする。画面の説明は短い一文にする。冒頭だけはサービス名を小さく添える。

PALSの本物の操作録画を使う。UI、質問、回答、検証結果、ポインター操作を作り直さない。
テスト履歴、アカウント、URL表示をクロップで除く。入力と結果を読む場面は正面に戻す。
画面の移動は小さく、操作する箇所がわかる範囲にする。文字を巨大化して説明を補わない。

現在の26秒版では、素数の整除の説明とLeanコードを開く操作を見せる。
続いて「別の例」と明示し、平方展開の検証結果とLeanコードを紹介する。
PDF添付と行ホバーは、現行の実操作を撮影できた後に追加する。
再構成したUIを、その機能の実演として使わない。

英語版も収録画面の文字は変えず、字幕を英語にする。日本語UIの録画であることを明示する。
縦長では説明とコードを別のカットで大きく見せる。
Lean検証の対象は形式証明に限る。他社の偽の失敗画面や「すべての回答が正しい」という主張は使わない。
Runwayや生成サービスは使わない。映像、文字、カメラの動きをTesseractの編集可能なレイヤーとして残す。
```

## LPの動画を公開するための設定

ローカル開発では `public/media/` に置いた書き出しを表示する。生成物はGitへ追加しない。公開時はMP4・JPG・VTTを媒体用の保存先へ配置し、`NEXT_PUBLIC_PALS_PRODUCT_MEDIA_BASE` にそのベースURLを設定してビルドする。必要なファイル名は `pals-real-ja-landscape` と `pals-real-en-landscape` に、それぞれ `.mp4`・`.jpg`・`.vtt` を付けたもの。未設定の本番ビルドでは、動画部分と動画へのリンクを表示しない。

LPは型検査、対象ファイルのESLint、既存のLPテスト8件を通した。日本語コピーはnatural-japaneseとyomiyasuで点検した。動画の公開、広告配信、音の制作、PDF・行ホバーの追加撮影は未実施。
