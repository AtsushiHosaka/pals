# 待機候補Sの復旧処理が停止（2026-11-27）

待機候補SのDB承認後に確定処理が失敗しても、正規の復旧手順で通信を再開できるか確かめた。Mac実機のOrbStackで、隔離したAWS実装と受入用の代替ランナーを使った。統合コミット `c334c9a` で確定処理を一度失敗させ、通し試験を1回実行した。

Sの復旧処理は `same_window_fault_reconcile_not_verified` で停止した。通し試験は0/1件の成功で、Aの通知抑制は解除できた。復旧所要時間と費用は記録なし。Sの復旧が止まった原因を追試で調べる。[隔離試験の記録](../../seq42-local-rehearsal-2026-11-26.md#sのdb承認後に障害を起こした隔離試験)
