# 解説 v2（Draft を使う・答えを先に書く）の小規模測定（2026-11-10）

- 指標: 成功率（解説の品質）と費用。時間は参考。
- 仮説: 検証済みの証明に Draft を添え、答えと方針を先に書かせる仕様（v2）にすると、答えが先頭に来て、Lean にない論証の混入が減り、入力トークンも減る。
- 変更: pals-agent PR #101（`PALS_EXPLANATION_V2_ENABLED`、既定 off。未承認解説の配信は `PALS_EXPLANATION_FALLBACK_ENABLED`、既定 off、API 側の受け入れ待ち）。
- 測定の条件: `gpt-6-luna`（explain の既定）、v1 と v2 で同じモデル、推論の量は既定。評価セット `generation-eval-v1` の tuning 分割から6題（証明2、計算2、ε-δ1、反例1、ja 4・en 2）、各1回、2026-11-10。証明は筆者が Lean で書き、実 Lean（Mathlib）でコンパイルを確認した。Draft は筆者が書いた短い方針文で、パイプラインが生成したものではない。writer と reviewer は各アームの実装で、worker と同じ `_generate_reviewed_candidate`（最大2候補）を通した。
- 結果（n=6、各1回）:

| 指標 | v1 | v2 |
|---|---|---|
| 形式の失敗（writer の再試行） | 0 | 0 |
| 最終的に承認 | 6/6 | 6/6 |
| QA の不合格（修正に回った候補） | 1（行列式） | 1（x² ≥ 0） |
| 入力トークン計 | 41,436 | 13,279 |
| 出力トークン計 | 5,126 | 5,009 |
| 所要時間の計（writer+reviewer） | 81.2秒 | 82.1秒 |
| 推定費用（0.25/0.50 ドル/百万トークン） | 約0.013ドル | 約0.006ドル |

- 前後の例（解説本文。Lean 本文は載せない）:
  1. 行列式（ja、計算）。v1 の overview は「行列 A を考える。」で答えがなく、答え（0 ではない）は conclusion に回った。v2 の overview は「いいえ。行列式は $-1$ であり、$0$ ではありません。」で始まり、方針を続けた。
  2. x² ≥ 0（en、証明）。v1 は overview が「Fix an arbitrary real number $x$.」で、section に場合分け（$x\ge0$ と $x<0$）を書いたが、Lean の証明は `sq_nonneg` の直接適用で、場合分けはない。v2 は overview に結果と方針を書き、場合分けを「通常の実数算術ではこう成り立つが、検証済みの証明は一般の平方性質を直接使う」と区別した。ただし v2 の1回目は reviewer に不合格とされ、修正後に承認された。
- 判断: 既定 off のまま。向きは良いが、この測定だけで有効化は決めない。
- 費用: 本測定と試運転の合計で約0.025ドル（上限1ドル以内）。請求書との照合はしていない。
- 限界・未確認:
  - n=6、各1回で、差は偶然と区別できない。QA の合否は、アームごとに別の reviewer（v1 は既存、v2 は欠陥リストの rubric）が出したもので、直接比較できない。
  - Draft と証明は筆者が書いたため、本番の Draft（`attempt_evidence`）の質は反映されない。入力トークンの減少は、v1 の prompt が Lean に加え長い規則を含むこと、v2 の Draft が短いことの両方の影響を含む。
  - 所要時間は、v2 の QA 不合格1回で2倍になった1題を含む。差は無い。
  - 幾何などの `figure` を要する題は未測定（v2 は figure を出さない）。held-out は開いていない。
- 次にやること: パイプラインが生成した Draft と、tuning 分割の20題程度で、v1 と v2 を同じ reviewer（欠陥リストの rubric）で判定し直す。費用は事前に確認する。
