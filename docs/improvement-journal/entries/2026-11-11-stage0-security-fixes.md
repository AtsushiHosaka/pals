# 段階0の独立レビュー対応: 任意コード実行の修正と、関所を強めた測り直し (2026-11-11)

- 指標: 安全性(誤答0・任意コード実行なし)。その代償としての被覆と時間。
- 仮説: 命題の検証を許可リスト文法にし、Lean のプロセスを封じ込め、形式化の入口と関所を強めれば、独立レビューが再現した問題を塞げる。被覆は下がる。
- 変更: [pals-agent#106](https://github.com/AtsushiHosaka/pals-agent/pull/106)(88a7afe のレビューへの対応、895eb1a)。既定 off、本番の依頼経路に未接続、デプロイなし。
  - 許可リスト文法 `statement_grammar.py`(全入口で共有)。拒否リストの検証器が `by run_tac (IO.FS.writeFile …)` を受理し、Lean が実行した(レビューが再現、旧検証器が受理することを確認)。
  - `sandbox.py`: 環境の洗い出し、空の scratch、rlimit、プロセスグループ kill、macOS `sandbox-exec`。本番の検証器の隔離ではない。
  - `let` の緩和を除去、`autoImplicit` を切り、依頼の命題を単独で elaborate して型を比較する背面検査、背面検査を kill の前に、2つのフラグの入口ガード。
  - 形式化の依頼を囲み、答えを述べさせず、自明性の検査(結論が `True`、結論が仮定にある、仮定の空虚)、意味審査に加えて独立な往復検査、答えに「自動で作った形式化」と明記。
- 測定の条件: generation-eval-v1 の100題、常駐 Lean 1つ(サンドボックス内)、形式化・審査・往復検査は Luna(reasoning low)。2026-11-11。開始時のホスト負荷平均 12.5(他セッションと共有)、ワーカー起動 4.9 秒(空きの目安 3.6 秒)。別の実行(負荷平均 20〜30)も記録。
