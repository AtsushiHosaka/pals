# 回答の精度の回帰セットと、結論・x² 判定の修正（2026-11-14）

- 指標: 説明が回答まで到達する割合（生成失敗・QA の終端拒否の件数）、計算題で結論に答えが出る割合、正しい拒否が残る割合。対象は pals#319、#252、#233、#223。
- 仮説: main の説明経路には、(1) v2 の x² 文面検査が正しい ε-δ 説明を落とす、(2) v1 の QA が「答えのない結論」を承認する、という、プロンプトに触れずに直せる欠陥がある。
- 測定: 10 題（計算 5、証明 4、x² の ε-δ 1）× 腕 v1・v2 × 前 108 回・後 90 回。Luna（低）、推計費用 前 US$0.41・後 US$0.35。固定出力の QA は正しい出力 10 題と欠陥入りの出力 40 件を各 2 回。`held_out` は使っていない。
- 変更（pals-agent、審査プロンプトは変更なし）:
  - `_has_x_squared_epsilon_delta`: 最終の評価が別の `$…$` や連鎖（`<…=ε`）で書かれても受理する。ε で割った途中の式は最終評価と数えない。
  - 値を問う題では、結論に `$…$` の式を要求する（writer への差し戻し、QA の前）。保存済みの説明の読み込みは変えない。
- 結果:
  - v2 の x²: 前 3/9 回答（生成失敗 6）→ 後 9/9。
  - v1: 回答 104/108 → 86/90、終端拒否 4 → 4（変化なし。QA 拒否のあった試行は 12/108 → 19/90 で、ばらつきと区別できない）。
  - 固定出力 QA: main の v1 は「答えなし」の結論を 0/10 しか拒否しない（全て承認）。コードの検査は、値を問う題 4 つの 8/10 を QA の前に止める。誤検出は 0/87。`dual_power` の題文は判定にかからず残る。
