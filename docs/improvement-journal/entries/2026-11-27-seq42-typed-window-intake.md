# seq42の切替と復旧の実測を署名ゲートで再検証

`23957d6` で待機候補Sへの切替と前任Pへの通常復旧を隔離OrbStackで計測した。切替ではAの通信先を外してからSを登録するまで282.512秒、通常復旧では前任を再登録するまで216.767秒だった。同じツールと候補の原本で待機系の4試行を実行し、全件の証跡を集約して再検証した。

署名ゲートは切替と復旧の実測を読み取れた。代替ランナーと本番の受入検査の差から計算する倍率は約798倍となり、換算後はどちらの経路も1,800秒を超えた。計測には実モデルを使っていない。 [隔離試験と署名予算の記録](../../seq42-local-rehearsal-2026-11-26.md#同じツールで通常の復旧を再計測)
