# モデル呼び出し測定の生データ 2026-11-07

`docs/model-call-latency-measurement-plan-2026-11-07.md` の測定の記録です。質問本文・Lean本文・利用者情報は含みません（カードの命題は公開カタログのものです）。

- `s1a-*`: Luna low を Terra の12枚で実行。`s1b-*`: Terra medium を Luna の12枚で実行（`s1b2`/`s1b3` はAPIエラーで途中終了したカードの再実行）。`dry.jsonl`: 試走。
- `run.sh`: 実行スクリプト。`read_key.py`: git管理外の `.env.local` からキーを読む（値は出力しない）。パスは測定時のもので、環境に合わせて直す。
- `sim.py`: 方式A/Bの机上計算（ブートストラップ）。
- 注意: `s1b*` の再実行は、APIエラー（モデル呼び出し0回、または途中）で終わったカードのみ。Luna の12枚側の Luna 時間は 11-03 の並列実行のもの（`sim.py` に埋め込み）で、今日の逐次実行とは条件が異なる。
- `sim_matched_12.py`（2026-11-09 追加）: `sim.py` と同じ定義で、Luna の時間が同日の逐次実行である12枚だけの比較。実行するとデータ（`s1a-*.jsonl` など）をこのディレクトリから読む。
- `sim.py` の `S` は、実行時の作業用ディレクトリの絶対パスのままで、再実行するには、`s1*.jsonl` のあるこのディレクトリに直す。`sim.py` は `elapsed_seconds` を使い、呼び出しごとの時間は記録がない。
