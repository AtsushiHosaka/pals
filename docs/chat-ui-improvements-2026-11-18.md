## 表示と状態の扱い

アイコンと本文の間隔を既存の回答列と揃え、状態と時計を同じ行へまとめる。長い状態文は本文列内で折り返す。時計は要求のサーバー作成時刻を基準にし、検証開始でリセットしない。
