# 初等幾何の図コンポーネント

状態: 提案中（ユーザー未承認）。承認されるまで、実装の根拠にしない。

既存の [MRD-002・003・004・010・011](../mathematical-reasoning-and-diagrams/requirements.md) を前提とする。
設計案は [docs/geometry-figures/design.md](../../docs/geometry-figures/design.md) にある。

| ID | 求める振る舞いと受け入れ条件 |
| --- | --- |
| GF-001 | 回答は、部品名と頂点の対応を宣言するだけで図を呼び出せる。回答は座標、TikZ、SVG、HTML を書かない。 |
| GF-002 | 三角形（合同、相似、外心、内心、重心、垂心、傍心、チェバ、メネラウス）と円（円周角、接弦、方べき、円に内接する四角形、接線の長さ）に部品を用意する。 |
| GF-003 | 図の情報は、頂点ラベル、記号、短い数式で伝える。図の中に説明文を置かない。記号の種類は閉じた一覧とし、一覧にない記号は受け付けない。 |
| GF-004 | 部品ごとに必要な頂点の枠を型で固定する。枠の過不足、未知の部品、未知の記号、対応しない頂点を指す記号は受け付けない。 |
| GF-005 | 図に現れる頂点ラベルと、仮定・結論を表す記号は、検証済みの証明の宣言に対応づける。対応を確かめられない図は、検証済みの命題に結びつけて表示しない。 |
| GF-006 | 図の描画の成否は、証明の状態、回答の状態、一致の判定を変えない。図の寸法は仮定にならない。図は説明図と分かる形で表示し、検証済みの印を付けない。 |
| GF-007 | 図の不正や描画の失敗は、その図だけに閉じる。本文、Lean ソース、質問などの操作は隠れない。 |
| GF-008 | 1回答の図をすべて同時に表示でき、同時表示の数を理由に失敗しない。 |
| GF-009 | ラベルは TeX や HTML として解釈されない。図に重なる矢印や線は区別できる。 |
| GF-010 | デスクトップ幅と 375px 幅のどちらでも、ラベルと記号が読め、ページが横にはみ出さない。再読み込みの後も同じ図を表示する。 |
| GF-011 | 読み上げ用の説明を、宣言した内容から回答の出力言語で作る。記号の意味は、文字を増やさずに確認できる。 |
| GF-012 | 同じ宣言からは同じ図と同じ TikZ ソースを作る。TikZ ソースはコピーできる（MRD-004）。 |
| GF-013 | グラフの部品と、呼び出し形式・記号の考え方をそろえる。**未確定**: グラフ機能の場所を確認できていない。 |

## 範囲外

- カードと Lean の補題の追加は、Draft/Recipe DB 拡充の作業が担当する。部品の存在は、その定理の検証済みの対応を意味しない（MRD-011）。
- 可換図式は対象にしない。
