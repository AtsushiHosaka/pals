# 初等幾何とグラフの図コンポーネント

状態: ユーザー承認済み（2026-11-03。GF-016、GF-017 も同日に承認）。チャットへの直接埋め込みは、ユーザーの指示で最初の案から変更した。

既存の [MRD-002・003・004・010・011](../mathematical-reasoning-and-diagrams/requirements.md) を前提とする。
設計は [docs/geometry-figures/design.md](../../docs/geometry-figures/design.md) にある。

| ID | 求める振る舞いと受け入れ条件 |
| --- | --- |
| GF-001 | 回答は、テンプレート名とパラメータだけで図を呼び出せる。回答は座標、TikZ、SVG、HTML を書かない。 |
| GF-002 | 三角形（合同、相似、外心、内心、重心、垂心、傍心、チェバ、メネラウス）と円（円周角、接弦、方べき、円に内接する四角形、接線の長さ）にテンプレートを用意する。 |
| GF-003 | 図の情報は、頂点ラベル、記号、短い数式で伝える。図の中に説明文を置かない。記号の種類は閉じた一覧とし、一覧にない記号は受け付けない。色はテーマの色だけを使う。 |
| GF-004 | テンプレートごとに必要な頂点の枠を型で固定する。枠の過不足、未知のテンプレート、未知の記号、対応しない頂点を指す記号は受け付けない。 |
| GF-005 | Lean で検証した回答の図では、頂点ラベルが Lean ソースの点の名前に現れることを確かめる。確かめられない図は表示しない。回答本文と矛盾する図は、独立レビューで落とす。 |
| GF-006 | 図の描画の成否は、証明の状態、回答の状態、一致の判定を変えない。図の寸法は仮定にならない。図は説明図と分かる形で表示し、検証済みの印を付けない。 |
| GF-007 | 図の不正や描画の失敗は、その図だけに閉じる。本文、Lean ソース、質問などの操作は隠れない。 |
| GF-008 | 1回答の図をすべて同時に表示でき、同時表示の数を理由に失敗しない。 |
| GF-009 | ラベルは TeX や HTML として解釈されない。 |
| GF-010 | デスクトップ幅と 375px 幅のどちらでも、ラベルと記号が読め、ページが横にはみ出さない。再読み込みの後も同じ図を表示する。 |
| GF-011 | 読み上げ用の説明を、宣言した内容から回答の出力言語で作る。記号の意味は、タップまたはフォーカスで確認でき、常時の文字を増やさない。 |
| GF-012 | 同じ呼び出しからは同じ図と同じ TikZ ソースを作る。TikZ ソースはコピーできる（MRD-004）。 |
| GF-013 | 多項式のグラフと微分のグラフを、同じ呼び出し形式と同じ部品で表示する。 |
| GF-014 | 図は回答の本文の下に直接埋め込む。開くための操作やサイドパネルを挟まない。 |
| GF-015 | 本文の段落を図のステップに対応づけられる。段落へのホバー、フォーカス、タップで図が変わる。本文の文字は書き換えず、この操作はモデルを呼ばない。 |
| GF-016 | カタログ再利用の回答（`lean_catalog`）にも図を付けられる。回答の確定時にモデルを呼ばず、再利用経路の呼び出しを増やさない。図は Recipe の封印の外に置き、図のないカードの保存形式と `entry_sha256`、`answer_sha256` を変えない。 |
| GF-017 | カタログの図は Recipe ID と本文の digest の組に結びつき、API だけが付ける。本文が変われば図は付かない。worker が送った図は使わない。カタログの図のラベルは保存済みの本文に現れることを確かめる（Lean に点の名前がないカードがあるため）。追加の前に、作者とは別の審査を1回行う。 |

## 範囲外

- カードと Lean の補題の追加は、Draft/Recipe DB 拡充の作業が担当する。テンプレートの存在は、その定理の検証済みの対応を意味しない（MRD-011）。
- 可換図式は対象にしない。
- 本文を LLM が毎回書くカタログ回答（`entry_sha256` がない旧経路）には図を付けない。保存済みの本文に結びつけられないため。
