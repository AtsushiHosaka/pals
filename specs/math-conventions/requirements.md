# Math conventions

Status: WORKING — ユーザーの2026-10-05の指示に基づく。専門家にも使われることを前提に、零環を整域に含めるかのような流儀の違いを黙って決めない。関係するときに一度だけ確認し、答えを設定に保存し、設定の一覧から変更できるようにする。

## Purpose

数学の主張の真偽が、分野や教科書で分かれる約束事（流儀）に依存することがある。PALS はそれを推測で決めず、学習者に一度だけ確認して以後の証明に使う。どの約束事を前提にした回答かを、回答と設定から確認できるようにする。

## Requirements

| ID | Requirement |
|---|---|
| MCV-001 | PALS は約束事の固定カタログを持つ。各項目は ID、「含める」読みと「含めない」読み、ゲストに使う既定の読み、題名、確認文、説明を 4 言語（en・ja・zh-Hans・zh-Hant）で持つ。v1 の項目は design に列挙する 11 件とする。カタログにない流儀は、従来どおり教科書の標準的な定義を採り、評価した命題に明記する（PFR-014）。 |
| MCV-002 | ログイン中の学習者は、項目ごとに「関係するときに確認する（既定）」「含める」「含めない」のいずれかを設定に保存できる。設定画面にはカタログの全項目を、題名・説明・現在の設定とともに一覧で表示し、いつでも変更・確認に戻すことができる。 |
| MCV-003 | 証明要求の評価で、ある約束事の読みによって主張の真偽が変わり、学習者の設定が「確認する」で、その要求でまだ答えていない場合、Lean にかける前に `needs_input` でその項目を確認する。選択肢は「今回だけ含める」「常に含める」「含めない」の 3 つとする（Claude の許可確認の allow once・always allow・deny に相当）。1 回の確認では 1 項目だけを聞く。 |
| MCV-004 | 「今回だけ含める」はその要求にだけ適用し、設定を変えない（次に関係する要求で再び確認する）。「常に含める」と「含めない」はその要求に適用し、同時に学習者の設定に保存する。以後、その項目は設定が「確認する」に戻されるまで聞かない。選択肢以外の自由記述の答えは、通常の前提の答えとして扱い、設定を変えない。 |
| MCV-005 | 設定済みの項目は確認せずにその読みで評価し、Lean 検証に渡す命題にその読みを明記する。読みを採った結果、主張が偽になりそうなら、PFR-014 の反例の確認に進む。 |
| MCV-006 | 回答（Lean 検証中・検証済み・失敗を含む）には、その要求で真偽に関係した約束事と採った読み、その出どころ（設定・今回だけ・標準）を表示する。ログイン中の学習者には、そこから設定の約束事一覧を開く手段を示す。 |
| MCV-007 | ゲストは設定を持たない。ゲストには約束事を確認せず、カタログの既定の読みを使い、MCV-006 と同じ表示で採った読みを示す。 |
| MCV-008 | 約束事の設定と要求ごとの適用記録は、その学習者と要求の所有者だけが読める。worker が受け取るのは、評価中の要求に必要な読みと確認の可否だけとする。worker は設定を書き換えられず、カタログにない ID や、設定・今回の答え・既定のどれとも一致しない読みを適用したとは記録できない。 |
| MCV-009 | 約束事の保存先がまだリリースされていない環境では、確認・保存・表示を行わず、従来の振る舞い（標準的な定義を採って明記する）を保つ。設定画面はその旨を示す。 |

## Acceptance

- 零環が関係する主張（例：有限整域は体）で、設定が「確認する」のログイン学習者には、証明の前に 3 択の確認が出る。「今回だけ」を選ぶと設定は変わらず、次の関係する要求で再び確認される。「常に含める」または「含めない」を選ぶと設定に保存され、次からは確認されない。
- 設定画面に 11 項目が並び、各項目を「確認する／含める／含めない」に変更できる。変更は次の要求から使われる。
- 回答に「この回答の前提」として採った読みと出どころが表示され、ログイン中なら設定を開ける。
- ゲストには確認が出ず、既定の読みが表示される。
- 関係しない主張（例：x² の連続性）では確認も表示も出ない。
