# PALS Product Requirements

## Purpose

PALS の最小体験は、数学の問いから Lean で検証された証明と理解しやすい説明を得ることです。
この文書は学習者に見える振る舞いだけを定義し、実現方法は定義しません。

## Requirements

| ID | Requirement |
|---|---|
| CORE-001 | 学習者は、自然言語の数学問題または形式的な命題を証明要求として送れる。 |
| CORE-002 | PALS は証明候補を生成し、その証明の Lean source が Lean のコードとして `sorry`、`admit`、`axiom`、`constant`、`opaque`、または `unsafe` を一切含まず、その実際の Lean 検証に成功し、その source 内でこの証明候補の対象として一意に識別された形式的命題が元の証明要求に対応し、証明候補の論理が妥当であることを生成担当とは別セッションの LLM がレビューして成功した場合だけ、その証明を `verified` と扱う。 |
| CORE-003 | 検証済み証明には、その証明に基づく当該チャットに保存された言語の説明を提示する。学習者は説明の一部について追加質問でき、その説明に基づく当該チャットの言語の回答を受け取れる。 |
| CORE-004 | 生成、Lean 検証、または証明要求と形式的命題の対応および証明候補の論理を確認する LLM レビューが失敗した場合、成功を捏造せず、対象の証明候補を未検証または失敗として当該チャットの言語で明示する。説明または追加回答が失敗した場合は、その出力を当該チャットの言語で失敗として明示する。CORE-002 の全条件を満たして既に `verified` と表示された証明は、後続する説明または追加回答が失敗しても `verified` のままとする。 |
| CORE-005 | 学習者は証明の Lean source を確認できる。`verified` と表示された証明では、確認する source は `verified` 判定に使用した source と同一である。通常の学習画面では説明を初期表示し、Lean source は学習者が source 表示操作をしたときだけ表示する。 |
| CORE-006 | PALS は説明または追加回答を学習者に提示する前に、生成担当とは別セッションの LLM によって、その出力が対象の検証済み証明（追加回答では対象の説明も）に基づくことをレビューする。レビューに成功した出力だけを提示し、レビューが失敗した場合はその出力を当該チャットの言語で失敗として明示する。証明の `verified` 状態は変更しない。 |
| CORE-007 | 学習者は、英語 (`en`)、日本語 (`ja`)、簡体中文 (`zh-Hans`)、繁體中文 (`zh-Hant`) から出力言語をアカウント設定として選択できる。設定は永続化し、未設定時は英語を用いる。 |
| CORE-008 | 学習者は Project 配下にチャットを開始できる。チャットは Project に属さない形でも存在できる。PALS はチャットの開始時に、その時点のアカウントの出力言語を当該チャットの言語として保存する。証明要求、説明、追加回答、失敗表示および状態表示は当該チャットに属し、保存した言語を用いる。アカウントの出力言語を変更しても、既存のチャットの言語は変更しない。 |
| CORE-009 | Chat 導入前から存在する各 proof job は、Project に属さない専用のチャットに移行する。PALS はそのチャットの言語を日本語 (`ja`) として保存する。 |

## Acceptance Criteria

- 自然言語の数学問題と形式的な命題のいずれも、証明要求として送信できる。
- `verified` と表示する証明の Lean source は、Lean のコードとして `sorry`、`admit`、`axiom`、`constant`、`opaque`、または `unsafe` を一切含まず、その同一 source の Lean 検証に成功している。その source 内でこの証明候補の対象として一意に識別された形式的命題と元の証明要求の対応および証明候補の論理は、生成担当とは別セッションの LLM レビューに成功している。
- 検証済み証明には当該チャットに保存された言語の説明を提示する。説明の一部への追加質問に対する回答は、当該チャットの言語で、対象の説明および同一の検証済み証明に基づく。
- 生成、Lean 検証、または証明要求と形式的命題の対応および証明候補の論理を確認する LLM レビューが失敗したときは、対象の証明候補を未検証または失敗として当該チャットの言語で明示し、`verified` と表示しない。説明または追加回答が失敗したときは、その出力を当該チャットの言語で失敗として明示する。これらの出力には `verified` の状態を付与せず、CORE-002 の全条件を満たして既に `verified` と表示された証明は `verified` のままとする。
- 通常の学習画面では説明を初期表示する。Lean source は学習者が source 表示操作をしたときだけ表示し、`verified` と表示された証明では、その source は `verified` 判定に使用した source と同一である。
- 説明または追加回答は、学習者に提示する前に生成担当とは別セッションの LLM のレビューに成功する。レビューが失敗した場合はその出力を当該チャットの言語で失敗として明示し、証明の `verified` 状態を変更しない。
- アカウントの出力言語設定は `en`、`ja`、`zh-Hans`、`zh-Hant` のいずれかとして永続化する。設定がない場合は `en` を用いる。
- 学習者は Project 配下にチャットを開始できる。チャットは Project に属さない形でも存在できる。新しいチャットには開始時点のアカウントの出力言語を保存し、そのチャットに属する証明要求、説明、追加回答、失敗表示および状態表示に用いる。アカウントの出力言語を変更しても、既存のチャットの言語は変わらない。
- Chat 導入前から存在する各 proof job は、Project に属さない専用のチャットへ移行し、そのチャットには `ja` を保存する。
