# Project materials and OCR-backed answers

Status: WORKING. 実装済みの範囲を正本化する。根拠は2026-09-30の回答（D1–D12、[提案](../../docs/proposals/project-materials/requirements.md)）、2026-10-04の実装依頼、および2026-10-05の「OCRのUIは必要ないので削除してよい」というユーザー判断。価格・token付与量は [individual-billing](../individual-billing/requirements.md) が扱う。

## Current product decision

資料に関する学習者向けUIは提供しない。2026-10-05 にプロジェクトホームの資料一覧・追加・削除・再読取り・ダウンロード、および回答下の OCR 出典表示を削除した。資料API、既存資料に基づく回答、出典の保存・検証は維持する。資料UIを再び提供するには、配置を含めた新しい UI 決定が必要である。

## Non-goals

共同編集、公開共有、外部URL取込、ZIP・動画・音声・Office文書、資料だけによる証明の自動開始、資料の定理を無検証で Lean の公理にすること。

## Acceptance

- 50MB 境界、5件同時競合、偽 MIME、1,000 ページ PDF、日本語・スキャン混在、所有者分離、削除競合、出典と回答レビューの結合を実 PostgreSQL と実 OCR で確認する。
- 読取り失敗の資料が1件あるプロジェクトでも、その資料を名指ししない質問は受け付けられる。
- プロジェクトホームに資料管理UIが表示されず、回答下に OCR 出典が表示されない。保存済みの出典データは変更されない。
