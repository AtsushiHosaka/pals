# 画像と数式を扱うチャット

Status: WORKING。2026-10-07のチャット改修依頼と同日の回答に基づく。画像添付・公開共有・画面の再設計を含む。未決事項が残るため、画像機能全体の実装開始条件は満たしていない。

## 対象

Project内・Project非所属の会員チャットとゲストチャットで、画像と本文を扱う。入力欄と会話表示を再設計し、送信済みの数式を読みやすく表示する。Project資料の管理は[project-materials](../project-materials/requirements.md)、証明と検証は[pals-product-core](../pals-product-core/requirements.md)が定義する。

| ID | 学習者に見える振る舞い |
|---|---|
| CHAT-001 | 全ユーザーが、クリックによるファイル選択、ドラッグ＆ドロップ、画像の貼り付けでチャットに画像を添付できる。送信前に画像を確認・除去でき、送信後は対応するメッセージの履歴から閲覧できる。Project資料へ自動追加しない。 |
| CHAT-002 | 会員・ゲスト・公開共有の質問、補足回答、回答で、明示的にTeXで囲まれた数式を描画する。文中の`$...$`・`\(...\)`と独立した式の`$$...$$`・`\[...\]`を扱う。ユーザー入力の保存内容、コード、Lean sourceを表示のために書き換えない。解釈できない入力は読める原文を残す。 |
| CHAT-003 | 添付画像を問題文と決めつけず、依頼文と画像の関係を扱う。参考資料、図、途中の解答が添付されても、存在しない問題を作って証明を始めない。意図や画像の読み取りが確定できない場合は必要な確認を求める。 |
| CHAT-004 | 画像を含む依頼では実画像を回答処理に使う。画像が読めない、欠損している、処理に失敗した場合は理由を示す。画像を無視した本文だけの処理を、画像を扱った成功として表示しない。 |
| CHAT-005 | 会員の画像付きチャットでは、公開前の共有プレビューに画像を含める。公開リンクは確認済みの本文と画像を固定して提供する。後の会話や画像の追加で公開内容を更新しない。公開・所有権・取消は[chat-sharing](../chat-sharing/requirements.md)の契約に従う。ゲストの公開共有は追加しない。 |
| CHAT-006 | 入力欄と会話表示を再設計し、本文、添付、送信、処理中、確認待ち、失敗を同じ会話の流れで扱う。失敗した送信の本文と添付を保持して再試行できる。四言語、スマホ・タブレット・PC、キーボード操作、日本語入力の確定操作に対応する。既存の履歴、検索、新着表示、設定、Lean source閲覧を維持する。 |

## 未決事項

証明以外の説明・読み取りへの回答範囲、画像のみの送信、形式・枚数・容量、保持・削除期限、画像処理量に対応する利用枠を決める。ゲストは[public-guest-chat](../public-guest-chat/requirements.md)のセッション分離と利用制限を維持し、画像導入に必要な差分を確定する。CORE-012のLean必須条件は、回答範囲の決定前に緩めない。

## 受入条件

- 会員のProject内・非所属とゲストで、選択・ドロップ・貼り付け、プレビュー、除去、送信、履歴閲覧を実際のAPI・保存先・画像対応モデルで確認する。本文と画像の順序が同じ再送で、処理と利用枠を二重計上しない。
- 問題、参考図、途中式をそれぞれ添付し、依頼との関係を扱えることを確認する。図の条件を落としたOCRだけの処理で合格にしない。証明では既存のLean検証と独立レビューを通す。
- 不正形式、破損、上限超過、他人の画像取得、送信失敗、再読み込み、チャット・アカウント切替を確認する。別の会話や所有者へ添付が混入しない。
- 質問と補足回答で四種類のTeX区切りを確認する。コードは原文を表示し、不正なTeXや非対応の記法でも会話を読める。長い式はページ全体を横にはみ出させない。
- 共有のプレビューと匿名閲覧で本文・画像が一致すること、後の変更で更新されないこと、取消後に取得できないことを確認する。

会話の編集・分岐・再生成・停止、音声・動画・外部URL取込は、この仕様では追加しない。
