# Chat navigation: search and completion indicators

Status: WORKING. 実装済みの振る舞いを正本化する。完了ドットは2026-09-30のユーザー依頼に基づく（[実装記録](../../docs/chat-completion-indicators.md)）。

| ID | Requirement |
|---|---|
| CNAV-001 | 学習者はサイドバーの「Search chats」から、自分のチャットだけを Project 名・チャット内の質問文で検索できる。結果は新しい順に表示し、チャットのタイトル（最初の質問）・Project 名（非所属ならその旨）・作成日時・言語を示し、選択するとそのチャットを開く。空の検索語では最近のチャットを示す。続きの結果を順に読み込める。他アカウントのチャットや削除済み Project のチャットは含めない。 |
| CNAV-002 | 未表示の新しい回答があるチャットには、デスクトップ・モバイルとも、Project 配下と Project 非所属の両方でタイトルの横に小さな青い点を表示する。点は通知であり、Lean 検証済みを意味しない。回答済みの新しいリクエストと従来の検証済みジョブが対象で、処理中・失敗・取消・前提確認は対象外。 |
| CNAV-003 | チャットを開く、または画面上に結果が表示された時点で、その最新の完了を既読にする。初回取得時点の履歴は既読とみなし、その後の完了（同じチャットでの再度の完了を含む）だけを未読にする。既読状態はアカウントとブラウザごとに保持し、再読み込みや同じブラウザの別タブでも維持する。通信失敗で既存の点を消さない。端末間の既読同期は行わない。 |
| CNAV-004 | 完了状態の取得は本人のチャットのメタデータだけを返し、会話本文を返さない。表示中のタブだけが一定間隔で取得し、バックグラウンドのタブは取得も既読化も行わない。 |

## Acceptance

- 検索と完了取得は認証必須で、他アカウントの結果を返さず、`no-store` で応答する。
- 新しい回答の完了後に点が付き、開くと消え、再読み込み後も既読のまま残る。
- 4言語でアクセシブルな名前（例: “New result available”）を持ち、スマホ幅でタイトルが省略表示されても点が見える。
