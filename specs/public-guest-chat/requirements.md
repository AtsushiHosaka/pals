# Public landing page and guest chat

Status: WORKING — 2026-10-04 のユーザー依頼（公開LPとログアウト状態のチャット）および同日の「補足回答を含め1日3回」の明示指定に基づく。実装済みの振る舞いを正本化したものであり、本番公開の完了を意味しない。

## Scope

ログインしていない人が PALS を知り、アカウントなしで数学の質問を試せるようにする。アカウントの課金・履歴・Project には影響させない。

| ID | Requirement |
|---|---|
| GUEST-001 | 未ログインの `/` と、ログイン状態に関わらない `/about` は同じ公開LPを表示する。ログイン済みの `/` は従来のワークスペースを表示する。LPの送信は入力文と表示言語を引き継いで `/try` へ移る。 |
| GUEST-002 | `/try` では Cognito なしで数学の質問を送れる。回答は通常の証明リクエストと同じ AI 判断と独立レビューを通り、レビュー済みの回答だけを表示する。Lean 未実行の回答を形式検証済みと表示しない。前提が不足する場合は同じ質問の中で補足を求める。 |
| GUEST-003 | 送信できるのは JST の暦日ごとに、ゲストセッション単位とネットワーク単位でそれぞれ3回まで。最初の質問と補足回答はどちらも1回と数える。受理後に失敗した送信は数え、入力エラー・状態エラー・同一内容の再送・状態の読取りは数えない。全ゲストの1日合計にも上限（既定100）があり、補足回答を含む。JST 0時に回復する。 |
| GUEST-004 | ゲストの会話はアカウントの履歴・Project・課金枠・無料枠と分離する。登録・ログインしても自動では引き継がない。ゲストセッションは48時間で失効する。 |
| GUEST-005 | 公開ページとゲストAPIの応答はキャッシュ・インデックス・第三者への参照元送信を許可しない。変更操作は許可した Origin からのものだけを受け付け、セッションは HttpOnly の不透明 Cookie で識別する。本番ではクライアントIPを信頼できるプロキシのヘッダーからのみ判定する。 |
| GUEST-006 | LP・FAQ・ゲスト画面・上限到達表示は英語・日本語・簡体中文・繁體中文で同じ規則を説明する。公開ページでは有料プランを「準備中」とし、価格を掲載しない。 |
| GUEST-007 | ゲストチャットは明示的に有効化した環境でのみ動作する。無効または設定不備の場合は送信を受け付けず、その旨を表示する。 |

## Acceptance

- 3回目までの送信は受理され、4回目は補足回答でも拒否される。Cookie を消しても同じネットワークの残数は回復しない。
- ゲストのCookieではアカウントのチャット・Project・課金APIに一切アクセスできない。
- 同一内容の再送は既存の結果を返し、残数を減らさない。
- 4言語の表示が上記規則と一致し、スマホ幅で横スクロールが発生しない。
